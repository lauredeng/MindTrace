# MindTrace循理ai
面向高中数学，帮助教师批改作业，帮助学生顺着解题过程弄懂错题。在原项目中增量修改，固定使用 Python + Streamlit + DeepSeek API + SymPy + JSON。

## 最新界面与统计
批改过程冲突、参考解发布、批次防重和课堂同步已完成审计整改。见 [整改验收](AUDIT_FIXES_ACCEPTANCE.md)。
学生“深度辅导”现已接入受控Agent：模型选择追问、讲解或数学核验，程序校验证据/权限/预算并返回实际工具观察；保留直接答疑。支持自愿新题验证和教师复核。详见 [Agent实现与真实接口验收](AGENT_ACCEPTANCE.md)。
新增免账号课堂访问码：教师创建课堂并为学生发放个人学习码，两端在不同浏览器读取同一课堂记录，学习反馈可以回传。使用步骤、权限边界和实测见 [跨浏览器闭环验收](CROSS_BROWSER_ACCEPTANCE.md)。旧演示工作区保留，不自动迁移。
批次结果已区分完成、部分完成、失败和限流暂停；支持只重试未完成步骤。无教师确认数据时正确率显示“—”并说明原因。见 [故障恢复修复验收](BATCH_RECOVERY_ACCEPTANCE.md)。
首页预选、上传区排列和继续追问页面截图见 [本轮补充验收](HOME_FOLLOWUP_ACCEPTANCE.md)。
本轮交互修正：可点击预选的等宽角色卡片、固定角色切换按钮、无圆圈分段分类、教师平均正确率与详情跳转、解析后继续追问。见 [五项反馈验收](FIVE_FIXES_ACCEPTANCE.md)。
教师结果以按题错误人数热力图为核心，按三种题型分组，点击题目查看本题共性错误和原始证据。颜色只使用教师已确认错误人数，异常记录单列；可靠总分齐备才展示平均分。
错题本改为“全部错题/选择题/填空题/解答题”的卡片列表与详情，不再按知识点分类或筛选。错因页独立保留，修改分类后更新实际数量。
本轮学生错因统计使用可点击饼图，显示数量与百分比；教师矩阵使用绿、橙、红三个错误人数层次。详细布局、四张实际截图及验收结果见 [本轮界面验收](ACADEMIC_UI_ACCEPTANCE.md)。旧资料题型未知时不猜测，可在识别预览或结果中补全。

## 运行
本机双击 start.bat，打开 http://127.0.0.1:8501 。这是本机地址，不能作为给异地评委的分享链接。当前没有正式公网部署。

新环境：

    python -m venv .venv
    .\.venv\Scripts\python.exe -m pip install -r requirements.txt
    start.bat

服务端 Key 优先读取进程环境变量，其次 Streamlit Secrets；只有 development 允许项目 .env 后备。start.bat 是本机 development 保存模式。普通用户不申请、不填写 Key。实际密钥不要发到聊天、命令参数、Git或整个目录的压缩包。

## 教师：批改与班级统计
主导航：作业批改、班级错误分析、历史记录。

1. 全班使用 PDF 入口，最多 100 份，每名学生一份、单份最多 24 页。单名学生的图片入口最多 24 张，可调整页序。两种方式的单文件默认上限均为 20 MB（`.streamlit/config.toml` 的 `server.maxUploadSize`），每次总计最多 512 MB，每批最多 1600 条逐题作答。服务器通过 PATH 中的 Poppler（pdfinfo 和 pdftoppm）读取 PDF。旧 CSV 与手动补录在教师设置的兼容导入中保留。
2. 教师可在「班级学号名单」一次保存名单。PDF 以「学号.pdf」命名时会自动归属，保留前导零。同一批的重复学号或不在名单内的编号需要修正；无法匹配的作答可保留为匿名，仅供教师查看。单名学生照片可选填一次学号。系统分别识别各页的题干和作答，全部识别后在同一份作业内按题号、小问号配对，确认整份未答才计错。支持当前会话分批识别及重试；原件和页码随批次保留。共享演示模式的原件和待处理队列仅在当前会话中可用。
3. 确认保存为批次。打开“本次作业的参考答案”，填写已有答案，或为缺少答案的题生成 AI 草稿，核对后勾选并保存。题目归属相同的作答共用同一份确认答案，草稿不参与批改。
4. 点击“开始批改”。明确的单选、多选和受支持的填空答案可在本地判断，留白直接计错。证明题检查必要过程，接受有效替代解法。无参考答案或本地无法确定的作答由 AI 核验。更新某题参考答案后只重跑该题受影响的作答，历史判定和教师改判保留。
5. 短时限流会在本次操作内倒计时并自动继续，默认累计最多等待 120 秒。日额度、余额、较长中断或持续服务故障会保留进度并提示后续操作。已完成的步骤在同一工作区内复用。公开演示的上传识别进度仍属于当前会话。
6. 班级学情直接统计正确、错误和正确率，识别或判定异常单列。点击题目可以抽查学生原始作答和依据，教师可按需改判。
7. 历史记录可查看批次及导出批改CSV。没有评分规则时不生成分数；当前不自动给正式步骤分。

相同题目按完整题干内容关联；题号相同不代表同题。相同学生同题的重复批次在全局统计中取最近一份，不膨胀人数。AI分类不当作教师确认。公共题目录可减少重复题干输出，但仍要读取图片并人工确认；分区识别会保留成功区域，格式重试继续使用紧凑输出。阶段用量记录区分识别、参考答案生成和批改，费用仅在配置单价后估算。

构造材料体验入口仅在开发者模式可见；只导入原始材料，点击批改才产生真实调用，不加载预设诊断。

## 学生：解题、追问与错题本
主导航：AI解题与辅导、我的错题本、错因分析。

- 默认只查看当前会话的自主学习记录。教师可创建「按学号进入的演示课堂」并分享课堂链接，学生打开后输入学号查看该课堂历次作业；学号入口无身份验证，只使用虚构材料。常规课堂保留个人学习码。旧匿名批次不自动分配。
- 学生可以直接输入数学问题，也可以从同一输入框添加图片或 PDF（最多 5 个文件，合计 12 页）。附件经同意后按页识别，校对保存后可将随附的问题带到指定题目中发送。
- 完全没有作答也可以保存题目，选择先给提示、分步引导、完整解答；不要求先创建任务、诊断或练习。
- 有错误解答时可主动分析错误。可以让AI问一个有目的的问题，也可以直接追问步骤、条件或其他解法。保留四级提示，不强制固定追问轮数或训练。
- 分析发现的错误自动进入同一错题本；不会做的题可以主动收藏。同一学生同一道题不重复收录，保留各次原始来源。
- 每题保留原题、原始解答/原图引用、参考解、错误位置、知识点、AI原始分类、个人分类与修改历史。可修订、删除、恢复、搜索和导出。
- 使用十个主要错因及独立“证据不足”状态。默认一个主因、最多两个次因；学生确认或修正后再计入已确认统计。
- 知识补充与本题关联：例如公式遗忘给公式和适用条件，计算错误通常无需讲义。必要时主动点击“按当前错因补充讲解”。
- 按日期、题型和错因筛选错题与统计，点击类别能打开对应原题；不输出无依据的能力百分比。

## 保留与隐藏
旧任务分配、变式训练、学习证据画像、原始求导工作区等代码和数据接口完整保留。普通导航隐藏兼容入口；只有服务端启用开发者模式时，独立“设置”中才显示兼容工作区。设置不占主导航；学生只能下载自己的错题记录。默认产品不要求安排教学计划或强制训练。

## 数学与识别边界
高中十个模块均可进入大模型；可选SymPy仅核验有界多项式求导和显式四次以内实数多项式方程的局部解集。工具不覆盖时AI仍可分析，完整几何证明没有形式化保证。
原始引用优先按原文ID定位，模型引用措辞与原文分别保留。数学结论仍可能错误，不能保证所有高中题百分之百准确。
已有真实印刷图测试；当前没有足够真实学生手写、模糊拍照、多页拼接或复杂图形的质量证据。不用预设结果假装识别。

## 数据和安全
本机新数据继续使用 .local_data/classroom_v1.json，schema_version保持1，新增可选列表加载旧文件时补空，不覆盖原始记录。原 runs.json / student_sessions.json 保留在旧兼容入口；未自动将所有v0.2记录迁入新错题本。
原子写入、进程锁与存储版本冲突检查保留；本机匿名原图单独按哈希保存。不同资料切换不会混用上一学生的题目，关联来源还须匹配同一学生与同一题目。
未连接课堂时，默认production使用各会话内存，刷新/重启可能丢失。连接协作课堂后使用服务器独立JSON目录，正式托管必须配置持久卷。演示角色切换和自动学生关联不是身份认证，课堂码已提供教师/学生范围校验；真实班级的公开部署仍需HTTPS、持久卷、访问码保管和专项安全验证。长期存储与访问控制见 DEPLOYMENT.md。
服务端Key不进入业务JSON、错误日志或源码包；原有限额、输入限制、异常脱敏保持生效。
